# VLESS Aggregator для Happ

Небольшой агрегатор публичных VLESS-подписок. Он параллельно скачивает источники, понимает обычные и base64-подписки, оставляет только VLESS с `security=tls` или `security=reality`, удаляет дубликаты по параметрам подключения и проверяет DNS/TCP-доступность узлов.

## Текущий этап

Workflow проверяет до 2 000 TCP-доступных узлов через sing-box: для каждого он запускает HTTP-запрос через локальный SOCKS и принимает узел только при получении реального exit IP. `all-working.txt` при запуске с `--real-check` содержит только эти подтверждённые VLESS, а `tcp-open.txt` — результат дешёвой проверки.

Чтобы получить country-файлы, добавьте в GitHub Secrets ключ `MAXMIND_LICENSE_KEY` от MaxMind. Workflow скачает GeoLite2 Country, сохранит его в cache и определит страну по exit IP. Без ключа страны будут `ZZ`, но реальная VLESS-проверка продолжит работать.

## Запуск локально

```powershell
python src/main.py
```

Для проверки только парсинга и дедупликации без сетевых TCP-проверок:

```powershell
python src/main.py --skip-check
```

Обычная TCP-проверка теперь использует таймаут 2 секунды и 128 параллельных workers, а во время работы печатает прогресс. Параметры можно изменить: `--check-timeout 1.5 --check-workers 200`.

Для реальной проверки нужен установленный `sing-box` и `curl`:

```powershell
python src/main.py --real-check --sing-box-bin C:\path\to\sing-box.exe
```

По умолчанию `security=none` отбрасывается. Для диагностического запуска его можно оставить так:

```powershell
python src/main.py --include-insecure --skip-check
```

Результаты:

- `output/best.txt` — первые 10 узлов по TCP latency;
- `output/all-working.txt` — подтверждённые VLESS при `--real-check`, иначе TCP-доступные узлы;
- `output/tcp-open.txt` — TCP-доступные узлы во время `--real-check`;
- `output/countries/ZZ.txt` — временный файл до появления exit-IP GeoIP;
- `output/stats.json` — статистика запуска;
- `history.json` — простая история присутствия узлов по дедупликационному ключу.

Число лучших узлов меняется константой `TOP_N` в `src/main.py`.

## GitHub Actions

Workflow `.github/workflows/update.yml` запускается вручную или каждые два часа в 17 минут (`17 */2 * * *`). Он требует, чтобы Actions были разрешены, а workflow находился в default branch. Для автоматического коммита используется `contents: write`. Проверка ограничена 2 000 VLESS на один запуск: это не даёт одному workflow превратиться в многочасовой сетевой скан.

Источники находятся в `sources.json`. Если конкретный источник временно недоступен, запуск продолжает обработку остальных и записывает ошибку в `output/stats.json`. Источник rjsxrd пока отключён: опубликованный путь `vless-secure.txt` возвращает 404.

Публичные конфигурации могут быть небезопасными или принадлежать неизвестным владельцам. Не передавайте через них чувствительные данные и проверяйте требования законодательства и правила использования сети.
