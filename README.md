# VLESS Aggregator для Happ

Собирает публичные VLESS из `sources.json`, удаляет дубликаты и публикует все конфиги, адреса которых относятся к выбранным странам. Основная подписка: `output/best.txt`. Число конфигов не ограничено константой TOP_N; в этом режиме не исключаются VLESS с `security=none`.

Выбранные страны задаются в `TARGET_COUNTRIES` файла `src/main.py`: Беларусь, Казахстан, Финляндия, Эстония, Латвия, Литва, Польша, Норвегия, Грузия, Азербайджан, Нидерланды, Германия, Швеция и Турция. Это стартовый список соседей России и распространённых европейских направлений; его можно изменить одной строкой.

Страна определяется по IP-адресу сервера: для доменного имени сначала выполняется DNS-запрос, затем IP проверяется через IPinfo Lite. Узлы с неизвестной страной не попадают в подписку. У CDN и anycast страна адреса может отличаться от фактической страны выхода VLESS. Подключение, ping и скорость в этом режиме **не проверяются**, поэтому количество в описании — число найденных конфигов, а не подтверждённо рабочих.

## Настройка GitHub

Создайте секрет `IPINFO_TOKEN` в Settings → Secrets and variables → Actions. Он нужен для определения стран; ранее сохранённые IP повторно не отправляются до истечения 30 дней. Без секрета workflow завершится с ошибкой и не заменит подписку пустым списком.

Workflow `.github/workflows/update.yml` запускается вручную или каждые два часа по расписанию `17 */2 * * *`. Для автоматического коммита результатов нужен доступ `contents: write`.

## Формат подписки

`output/best.txt` содержит все подходящие конфиги, сгруппированные по стране, с именами вида `🇳🇱 NL #001`. `NO NAME #001` используется только как запасное имя, когда страну определить не удалось; в основной country-only подписке такие узлы не публикуются. В начале файла передаются [метаданные Happ](https://www.happ.su/main/ru/dev-docs/app-management): обновляемое имя `#profile-title` вида `Мои N конф. 21.09 12:00`, информационный блок `#sub-info-text` со временем сборки и количеством конфигов, а также порядок строк без сортировки по ping. Отдельные файлы находятся в `output/countries/`.

`output/stats.json` содержит число источников, уникальных и отобранных конфигов, статистику DNS/GeoIP и количество по странам. Старые файлы `all-working.txt` и `tcp-open.txt` удаляются при первом запуске нового режима, поскольку их названия больше не отражают способ отбора.

## Локальный запуск

```powershell
$env:IPINFO_TOKEN = "ваш-токен"
py src/main.py --country-only
```

Токен храните в переменной окружения, не добавляйте его в репозиторий. Публичные конфиги могут перестать работать в любой момент; итоговую доступность проверяйте в Happ из своей сети.
